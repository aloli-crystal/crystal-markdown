= Markdown Universal

Convertisseur Markdown universel pour Crystal.
Enchaine https://github.com/aloli-crystal/crystal-kramdown-asciidoc[crystal-kramdown-asciidoc] avec l'ecosysteme https://github.com/aloli-crystal/crystal-asciidoctor[crystal-asciidoctor] pour convertir du Markdown en PDF, EPUB, HTML et presentations reveal.js.

== Fonctionnement

Crystal Markdown utilise un pipeline en deux etapes :

. **Markdown -> AsciiDoc** via `crystal-kramdown-asciidoc`
. **AsciiDoc -> Format cible** via l'ecosysteme `crystal-asciidoctor`

[source,text]
----
Markdown --> AsciiDoc --> HTML
                     --> PDF
                     --> EPUB
----

== Formats supportes

[cols="1,1,2"]
|===
| Format | Extension | Backend

| HTML
| `.html`
| crystal-asciidoctor

| PDF
| `.pdf`
| crystal-asciidoctor-pdf

| EPUB
| `.epub`
| crystal-asciidoctor-epub3

| AsciiDoc
| `.adoc`
| crystal-kramdown-asciidoc
|===
