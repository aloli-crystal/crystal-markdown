= Markdown Universal

Convertisseur Markdown universel pour Crystal.
Enchaine https://github.com/aloli-crystal/kramdown-asciidoc[kramdown-asciidoc] avec l'ecosysteme https://github.com/aloli-crystal/asciicrystal[asciicrystal] pour convertir du Markdown en PDF, EPUB, HTML et presentations reveal.js.

== Fonctionnement

Crystal Markdown utilise un pipeline en deux etapes :

. **Markdown -> AsciiDoc** via `kramdown-asciidoc`
. **AsciiDoc -> Format cible** via l'ecosysteme `asciicrystal`

[source,text]
----
Markdown --> AsciiDoc --> HTML
                     --> PDF
                     --> EPUB
----

== Formats supportes

[cols="1,1,2"]
|===
| Format | Extension | Backend

| HTML
| `.html`
| asciicrystal

| PDF
| `.pdf`
| asciicrystal-pdf

| EPUB
| `.epub`
| asciicrystal-epub3

| AsciiDoc
| `.adoc`
| kramdown-asciidoc
|===
