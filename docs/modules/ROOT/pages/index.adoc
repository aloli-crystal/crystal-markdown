= Markdown Universal

Universal Markdown converter for Crystal.
Chains https://github.com/aloli-crystal/kramdown-asciidoc[kramdown-asciidoc] with the https://github.com/aloli-crystal/asciicrystal[asciicrystal] ecosystem to convert Markdown to PDF, EPUB, HTML, and reveal.js presentations.

== How It Works

Crystal Markdown uses a two-stage pipeline:

. **Markdown -> AsciiDoc** via `kramdown-asciidoc`
. **AsciiDoc -> Target format** via the `asciicrystal` ecosystem

[source,text]
----
Markdown --> AsciiDoc --> HTML
                     --> PDF
                     --> EPUB
----

== Supported Formats

[cols="1,1,2"]
|===
| Format | Extension | Backend

| HTML
| `.html`
| asciicrystal

| PDF
| `.pdf`
| asciicrystal-pdf

| EPUB
| `.epub`
| asciicrystal-epub3

| AsciiDoc
| `.adoc`
| kramdown-asciidoc
|===
