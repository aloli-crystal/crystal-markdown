== v0.1.7 — 2026-07-28

=== Changed

* Renommage des dépendances de l'écosystème (abandon du préfixe `crystal-`, `doctor`→`crystal`) :
  `crystal-kramdown-asciidoc` → `kramdown-asciidoc`, `crystal-asciidoctor` → `asciicrystal`
  (`~> 2.0.26.12`), `crystal-asciidoctor-pdf` → `asciicrystal-pdf` (`~> 2.3.24.108`),
  `crystal-asciidoctor-epub3` → `asciicrystal-epub3`, `crystal-rouge` → `rouge` (`~> 4.7.0.3`).
* Les appels API deviennent `Asciicrystal.convert` / `Asciicrystal.load`, les converters
  `AsciicrystalPDF::Converter` / `AsciicrystalEpub::Converter`. Le pied de page « the Asciidoctor
  ecosystem » est conservé (référence au projet upstream).

== v0.1.3 — 2026-04-29

=== Modifié

* **Module interne renommé** `CrystalMarkdown` → `Markdown`
  (convention Aloli : retrait du préfixe `Crystal` sur les modules
  internes pour s'aligner sur le nouveau nom du shard). Seul le nom
  du module change ; comportement et chemin `require` inchangés.

== v0.1.2 — 2026-04-29

=== Modifié

* **Repo GitHub renommé** vers `aloli-crystal/markdown` (convention
  de nommage Aloli : les créations originales abandonnent le préfixe
  `crystal-`). Les anciens liens redirigent automatiquement.
* Champ `name:`, cible de compilation et binaire CLI alignés sur le
  nouveau nom du repo. Fichier d'entrée renommé
  `src/crystal_markdown.cr` → `src/markdown.cr`. La cible `main:`
  pointe désormais sur la source `src/markdown.cr` au lieu du binaire
  compilé `bin/crystal-markdown`.
* Toutes les dépendances restent des portages (kramdown-asciidoc,
  asciidoctor, asciidoctor-pdf, asciidoctor-epub3, rouge) et
  conservent leur préfixe `crystal-` selon la convention.
* Le module interne `CrystalMarkdown` et le dossier sont inchangés —
  nettoyage reporté.
