== v0.1.7 — 2026-07-28

=== Changed

* Rename the ecosystem dependencies (drop the `crystal-` prefix, `doctor`→`crystal`):
  `crystal-kramdown-asciidoc` → `kramdown-asciidoc`, `crystal-asciidoctor` → `asciicrystal`
  (`~> 2.0.26.12`), `crystal-asciidoctor-pdf` → `asciicrystal-pdf` (`~> 2.3.24.108`),
  `crystal-asciidoctor-epub3` → `asciicrystal-epub3`, `crystal-rouge` → `rouge` (`~> 4.7.0.3`).
* The API calls become `Asciicrystal.convert` / `Asciicrystal.load`. The prose footer
  "the Asciidoctor ecosystem" is preserved as an upstream reference.

== v0.1.3 — 2026-04-29

=== Changed

* **Internal module renamed** `CrystalMarkdown` → `Markdown` (Aloli
  convention: drop the `Crystal` prefix on internal modules to match
  the new shard name). Only the module name changes; behaviour and
  `require` path are unchanged.

== v0.1.2 — 2026-04-29

=== Changed

* **GitHub repository renamed** to `aloli-crystal/markdown` (Aloli
  naming convention: original creations drop the `crystal-` prefix).
  Old links redirect automatically.
* `name:` field, build target and CLI binary aligned on the new repo
  name. Entry-point file renamed `src/crystal_markdown.cr` →
  `src/markdown.cr`. Build target now points to the source
  `src/markdown.cr` instead of the compiled `bin/crystal-markdown`.
* All dependencies remain ports (kramdown-asciidoc, asciidoctor,
  asciidoctor-pdf, asciidoctor-epub3, rouge) and keep their
  `crystal-` prefix per the convention.
* The internal module `CrystalMarkdown` and folder are unchanged —
  cleanup deferred.
